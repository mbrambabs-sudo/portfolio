- Construction Management and project delivery
- BOQs, measurement, valuations, payment certificates, variations and cost control

## Featured project: DiathoFlow

**DiathoFlow** is a real-world QS Consulting Company Command Centre designed, developed, tested and deployed for **Diatho Consulting**. It was handed over in 2026 and is currently used for company operations.

The portfolio documents the project as a professional case study, including:

- business problem and solution
- system capabilities
- security-first engineering
- testing and diagnostics
- high-level architecture
- development workflow
- professional and career relevance

## Run locally

Open index.html in a browser, or serve the project with a local web server:

    python -m http.server 8000

Then visit http://localhost:8000.

## Deployment

The site can be published using GitHub Pages by enabling Pages in the repository settings and selecting the main branch.
